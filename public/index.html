NekoAPI mengumpulkan puluhan fitur — AI, downloader, anime, games, pencarian — di satu REST API yang sama. Setiap request melewati lapisan keamanan: pembatasan laju per IP dan per perangkat, dengan notifikasi langsung ke Telegram saat ada aktivitas yang mencurigakan.

Tiga lapis perlindungan berjalan di depan setiap endpoint, bukan tempelan belakangan.
01 — IP

Rate limit per alamat IP

Setiap IP dibatasi sekian request per menit. Lewat batas, request ditolak dengan status 429 dan pesan yang jelas.

02 — Device

Rate limit per Device ID

Header X-Device-Id dilacak terpisah dari IP, supaya satu jaringan yang dipakai banyak orang tetap adil, dan satu perangkat tidak bisa ganti IP untuk lolos.

03 — Telegram

Notifikasi & webhook Telegram

Pelanggaran berulang otomatis diblokir sementara, dan admin mendapat notifikasi real-time lewat bot Telegram.
