Ketentuan Layanan

Terakhir diperbarui:

1. Penggunaan Layanan

NekoAPI disediakan apa adanya ("as-is") oleh Nimzz untuk keperluan pengembangan, eksperimen, dan integrasi pribadi maupun proyek pihak ketiga. Dengan mengakses endpoint apa pun di layanan ini, kamu dianggap menyetujui ketentuan berikut.

2. Batas Wajar (Rate Limit)

Setiap request dibatasi per alamat IP dan per Device ID (header X-Device-Id). Melebihi batas akan menghasilkan respons 429, dan pelanggaran berulang dapat mengakibatkan pemblokiran sementara. Jangan mencoba melewati pembatasan ini dengan memalsukan header atau merotasi IP secara agresif.

3. Larangan Penyalahgunaan

  • Dilarang menggunakan API ini untuk aktivitas ilegal, spam, atau serangan terhadap pihak ketiga.
  • Dilarang membebani server secara berlebihan (flooding) di luar batas rate limit yang wajar.
  • Dilarang menyamarkan identitas klien untuk menghindari sistem keamanan.

4. Ketersediaan Layanan

NekoAPI dijalankan dengan usaha terbaik, namun tidak ada jaminan uptime 100%. Endpoint bisa berubah, dihentikan, atau dimodifikasi sewaktu-waktu tanpa pemberitahuan sebelumnya.

5. Sumber Data Pihak Ketiga

Sebagian endpoint mengambil atau meneruskan data dari layanan pihak ketiga. NekoAPI tidak bertanggung jawab atas keakuratan, ketersediaan, atau hak cipta konten yang berasal dari sumber tersebut.

6. Batasan Tanggung Jawab

Pengembang tidak bertanggung jawab atas kerugian langsung maupun tidak langsung yang timbul dari penggunaan API ini. Gunakan dengan risiko yang kamu tanggung sendiri.

7. Perubahan Ketentuan

Ketentuan ini dapat diperbarui sewaktu-waktu. Penggunaan berkelanjutan setelah perubahan berarti kamu menyetujui ketentuan yang telah diperbarui.
