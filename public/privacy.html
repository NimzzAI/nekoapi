Kebijakan Privasi

Terakhir diperbarui:

1. Data yang Dikumpulkan

Untuk menjaga keamanan layanan, NekoAPI mencatat data teknis berikut pada setiap request: alamat IP, header X-Device-Id (jika dikirim), User-Agent, endpoint yang diakses, waktu, dan status respons. Data ini disimpan sementara di memori server untuk keperluan rate limiting.

2. Daftar Blokir

IP atau Device ID yang melanggar batas rate limit berulang kali dicatat ke daftar blokir sementara (data/blocked_clients.json) beserta alasan dan waktu kedaluwarsanya. Data ini otomatis terhapus setelah masa blokir berakhir.

3. Notifikasi Telegram

Jika fitur Telegram diaktifkan oleh operator server, ringkasan aktivitas (rate limit, pemblokiran, error) dikirim ke chat Telegram yang dikonfigurasi lewat variabel lingkungan. Isi notifikasi hanya berupa metadata teknis (IP, endpoint, waktu) — bukan isi body request kamu.

4. Tidak Ada Penjualan Data

NekoAPI tidak menjual, menyewakan, atau membagikan data teknis di atas ke pihak ketiga untuk tujuan komersial.

5. Layanan Pihak Ketiga

Beberapa endpoint meneruskan request ke API atau situs pihak ketiga untuk mengambil data (misalnya downloader atau pencarian). Permintaan tersebut tunduk pada kebijakan privasi masing-masing layanan pihak ketiga.

6. Kontak

Pertanyaan seputar privasi dapat disampaikan langsung ke pengembang, Nimzz, melalui kanal yang tertera di dokumentasi proyek.
